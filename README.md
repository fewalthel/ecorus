# Ecorus
Проект по верстке сайта 

1. Создание компонентов с поомщью библиотеки React
2. Перемещение по страницам сайта без перезагрузки с помощью React Routing
3. Более оптимизированные стили засчет SCSS препроцессоров
4. Запросы к api с помощью axios
5. Использование стороннего api для отображения точек на карте
